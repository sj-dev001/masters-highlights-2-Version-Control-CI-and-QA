# Screenshot Guide

Include screenshots in the final submission to prove the project works.

## Recommended Screenshots

1. **Homepage**
   - Show the Study Sprint Planner loaded in the browser.
   - Make sure the hero section, task cards, and task list are visible.

2. **Adding a Task**
   - Type a new task into the form.
   - Choose a priority.
   - Capture the screen after the new task appears.

3. **Automated Tests Passing**
   - Run `npm test`.
   - Capture the terminal showing all Vitest tests passing.

4. **Linting Passing**
   - Run `npm run lint`.
   - Capture the terminal after the command completes successfully.

5. **GitHub Actions Passing**
   - Open the repository on GitHub.
   - Go to the Actions tab.
   - Capture the green passing workflow result.

6. **GitHub Pages Deployment**
   - Open the deployed GitHub Pages URL.
   - Capture the live site in the browser.

7. **Pull Request Review**
   - Open a sample pull request.
   - Capture a peer review comment and the CI status check.

## Screenshot File Names

Use clear names:

- `homepage.png`
- `add-task.png`
- `tests-passing.png`
- `lint-passing.png`
- `github-actions-passing.png`
- `github-pages-live-site.png`
- `pull-request-review.png`
